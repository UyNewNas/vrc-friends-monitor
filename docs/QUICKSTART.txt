VRC Friends Monitor

适用于 Windows 10 / 11 x64。解压整个 ZIP 后运行 VRChatFriendNotifier.exe。

使用 VRChat 用户名和密码登录，按提示输入两步验证码。
好友列表中可为每位好友分别选择上线、下线通知。
名字后面的“复制 ID”按钮会复制该行好友的完整 ID。
点击“日志”选项卡可直接查看记录，支持日期、搜索和上下线筛选。
所有好友的上下线变化都会写入日志，暂停弹窗或未勾选通知时也会继续记录。

关闭窗口会收起到托盘。右键托盘图标的“退出程序”才会真正结束监控。
可在窗口内启用提示音、调整弹窗时长、设置开机启动。
更新前请从托盘退出旧版。会话、设置和日志会保留；程序位置变化后请重新设置开机启动。

本地数据：%LOCALAPPDATA%\VRChatFriendNotifier
settings.json：通知开关和选项。
session.bin：由 Windows DPAPI 加密的登录会话，密码不保存。
logs：按日期保存的普通文本日志，包含好友名称及 ID，不会自动清除。
日志时间为收到变化的本机时间，断网或未运行时发生的变化无法补记。
首次同步不会把已有在线好友记录为刚上线。

不要将密码、验证码、Cookie、会话文件或未脱敏的日志分享给别人。
