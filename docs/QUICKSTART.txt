VRC Friends Monitor

适用于 Windows 10 / 11 x64。解压整个 ZIP 后运行 VRChatFriendNotifier.exe。

使用 VRChat 用户名（不是显示名称）和密码登录，按提示输入两步验证码。
可选择身份验证器、邮箱验证码或一次性恢复码，验证码错误可以重试。
勾选“记住账号密码”后，登录及两步验证全部成功才会在本机加密保存。
下次打开登录窗口会自动填入，密码以掩码显示；更改用户名会清空旧密码输入。
升级后原来未保存过密码的账号，需要首次手动填写并勾选一次。
取消勾选会立即清除已保存的凭据；登录窗口和托盘菜单也有“忘记已保存账号密码”。
“退出登录”删除会话但保留已记住的账号密码；忘记凭据不影响当前会话、设置和日志。
也可点击“浏览器登录”，在独立的 Edge / Chrome 隐私窗口中完成官网登录和验证。
浏览器登录不需要在程序内填写密码；认证完成后自动返回程序，最长等待 10 分钟。
浏览器登录不会保存网页密码，也不会替换之前记住的账号密码。
需要已安装 Edge 或 Chrome；不读取日常浏览器资料，登录完成或取消后清理临时窗口和目录。
好友列表中可为每位好友分别选择上线、下线通知。
名字后面的“复制 ID”按钮会复制该行好友的完整 ID。
点击“日志”选项卡可直接查看记录，支持日期、搜索和上下线筛选。
所有好友的上下线变化都会写入日志，暂停弹窗或未勾选通知时也会继续记录。

关闭窗口会收起到托盘。右键托盘图标的“退出程序”才会真正结束监控。
可在窗口内启用提示音、调整弹窗时长、设置开机启动。
更新前请从托盘退出旧版。会话、设置和日志会保留；程序位置变化后请重新设置开机启动。

本地数据：%LOCALAPPDATA%\VRChatFriendNotifier
settings.json：通知开关和选项。
session.bin：由 Windows DPAPI 为当前用户加密的登录会话，启动时优先恢复。
credentials.bin：选择“记住账号密码”后加密保存的账号密码，只在可信设备上启用。
logs：按日期保存的普通文本日志，包含好友名称及 ID，不会自动清除。
日志时间为收到变化的本机时间，断网或未运行时发生的变化无法补记。
首次同步不会把已有在线好友记录为刚上线。

不要将密码、验证码、Cookie、会话文件或未脱敏的日志分享给别人。
